The problem

Pick a starting wave u(x, 0) on a ring-shaped road of length 1. The viscous Burgers equation says how it evolves: fast parts catch up with slow parts and steepen into sharp fronts (shocks), while a little viscosity smooths them.

∂u/∂t + ∂/∂x ( u²/2 ) = (ν/π) · ∂²u/∂x²

The factor is ν/π, not plain ν. That is the convention used by the PDEBench data this model learned from, and we checked it against the stored solutions.

  • ν = 0.01 (fixed)
  • 256 grid points
  • x ∈ [0, 1), periodic
  • t from 0 to 2 in 201 steps

A Fourier Neural Operator (FNO), a neural network trained on 4,000 simulations, predicts the whole evolution in one pass. Next to it we run an ordinary numerical solver on the server, so you can see where the network is right and where it is not.

Please read: what this model cannot do

  • Shocks are its weak spot. Close to a shock the error was about 3× larger than elsewhere (0.134 vs 0.042 in tests).
  • It does not copy its own input perfectly. At t = 0 the output is off by about 1.6% (relative), so the first frame is not exact.
  • It does not conserve mass. The total amount of "stuff" drifts about 100× more than in the reference data. The numerical solver conserves it to rounding error.
  • One viscosity, one family of inputs. It was trained only for ν = 0.01 and smooth random wave mixtures at 256 points. Anything else is outside what was tested.
  • A warning is not a guarantee either way. Taller, noisier or much more wiggly inputs raise a warning, but milder problems (for example a square wave) can be wrong without one. Always look at the solver next to it.
  • It is a learned approximation, not a proof. The numerical solver is the reference; the FNO is just much faster.
