# burgers-fno-service

PDE solutions as a service: a Fourier Neural Operator (FNO) trained on a PDEBench 1D Burgers dataset,
served by a FastAPI app. **Work in progress. Nothing has been trained or deployed yet.**

Status of every claim in this README will be recorded in the final version under
"Verified / Not verified / Failure modes". Until then, treat nothing here as a result.

Data: PDEBench (Takamoto et al., 2022), DaRUS DOI 10.18419/darus-2986, licence CC BY 4.0.
See TIMELINE.md for the build log and deadlines.
